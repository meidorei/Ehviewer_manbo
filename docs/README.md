## 维护约定

功能和行为写入对应专题；每次改动在根目录 `说明.md` 记录内容、影响范围、版本、验证结果和限制。不要把历史测试结果写成当前验证通过，也不要用源码版本替换旧 APK 的真实元数据。

根目录 `AGENTS.md` 是本机 Agent 工作规范，目前被 Git 忽略；其约束仍适用于本机操作。共享的开发流程见[开发与构建](build.md)。

本次整理覆盖本分支维护的项目文档与中英文商店描述。上游作者的历史原文增加归档提示，原始补丁单独保存；第三方库文档、许可证、构建脚本及生成文件保持原内容。
