# 使用指南

[文档索引](README.md) · [常见问题](troubleshooting.md)

## 本地追更与服务器订阅

在列表或详情页长按标签，选择“追更”；再次长按可取消。右侧追更栏显示本机保存的标签，管理页支持搜索与删除。标签库可用时，名称显示中文翻译，下方保留原始查询。

本地追更不依赖服务器订阅，也不要求登录；实际能访问的画廊仍取决于站点、网络和账号权限。左侧“订阅”打开服务器 Watched，标签菜单中的服务器订阅、排除操作仍需要登录，两者是独立数据。

新条目先显示零基线，后台再细化从哪个时间开始计新增。第一次建立基线不会把全部已有漫画当作更新。

## 检查追更和书签

点击书签或追更抽屉的刷新入口，选择“全局中文扫描”，均会用同一次中文全局扫描同时更新全部书签和追更；两栏显示同一任务进度，可从任一栏暂停、继续或停止。启动对话框显示两类数量与各自扫描边界。一栏为空仍更新另一栏，两栏皆为空时提示无可更新项目、不联网。逐标签、逐书签检查仍只更新对应类别；长按书签可以只检查这一项。

| 方式 | 行为 |
| --- | --- |
| 全局中文扫描 | 中文全局列表只扫描一遍，同时匹配追更和书签；未覆盖的追更逐标签补查，书签按原规则连续分页补查 |
| 逐标签检查 | 本地追更逐个读取标签第一页，未覆盖旧边界时显示数量下界 |
| 逐书签检查 | 连续翻页到旧边界或列表末尾，完成后保存新增 GID |
| 单书签检查 | 使用相同的书签分页规则，只处理所选书签 |

高级设置中的全局扫描上限为 1–300 页，默认 30 页；这是共享全局扫描的上限，不是逐书签扫描只读取 30 页。搜索请求间隔为 1.0–10.0 秒，默认 3.2 秒；小于 3.0 秒需要确认。修改间隔只影响新任务，暂停后继续沿用原任务设置。

联合全局任务暂停后继续（包括降级阶段）会重新从第一页扫描，沿用原任务请求间隔；旧版暂停的单类任务仍按原类型恢复。两栏任务历史同步展示联合任务结果，全部成功才更新两类成功时间。已成功提交的项目保留结果，停止任务不会回滚这些结果；尚未完成的书签分页不提交半截结果。

## 重置书签扫描基线

长期没有检查书签、积压更新导致扫描太慢时，可以打开“设置 → 高级 → 重置所有书签扫描基线”。确认后，本机所有书签从重置时刻开始检查，跳过此前尚未检查的历史更新；已有未读数字、未读明细和“上次更新到这”分割线保留，书签名称、条件和排序不变。

重置只操作本地数据，不发起网络请求，也不会自动开始检查。重置所在秒及以前的内容视为历史，下一秒起仍可计为新增。重置后等待一段时间再检查，会统计这段时间内的新内容。该功能同样适用于账号切换和 E/EX 回退，但不会让不支持更新的查询变得可更新，也不改变本地追更。

运行中或已暂停的更新任务须先停止；可在抽屉刷新入口打开任务详情，已暂停任务也提供“停止”按钮，无须先继续联网。没有书签时不写入数据。重置不能恢复被跳过的历史更新，确认前请核对提示。

## 重置追更扫描基线

“设置 → 高级 → 重置所有追更扫描基线”位于书签重置按钮下方，两者分别操作。追更重置从当前时刻开始统计后续更新，跳过此前尚未检查的历史内容；追更标签、已有未读数字和明细、阅读分割线、真实检查时间保留。重置所在秒视为历史，下一秒起可以计新增。

该操作只写本地数据，不联网、不自动检查更新，不重置书签或服务器 Watched。运行中或暂停的更新任务须先停止；空列表不会写入数据。全局扫描会从新的有效起点开始，逐标签仍使用原有第一页检查规则，追更最多保存 21 条未读明细。

## 未读数字和联动已读

- `0` 表示当前没有记录的未读更新；未初始化、失败和不支持查询应结合状态文字判断。
- `1–20` 显示数量；超过显示范围或计数只能确定下界时显示 `20+`。
- 书签保存全部未读 GID；本地追更最多保留 21 条明细。旧版本已裁掉的书签 GID 不会自动恢复。

成功打开一个书签会清除进入前捕获的未读批次；其他书签中的相同 GID 也会联动扣减。打开失败不会清除，打开过程中新增且不属于该批次的 GID 会保留。合法空结果也能清除原批次，避免站点已删除画廊留下永久计数。

这是“成功打开列表”的已读规则，不等于逐本阅读完漫画后才清零。

## 书签管理与检查报告

书签保存完整搜索条件。重命名保留更新状态，修改查询条件会重建基线。管理页支持名称和原始查询搜索；过滤期间禁用拖拽，清空搜索恢复排序。

书签设置页的“检查书签”只读取本地数据，报告重复查询和扫描开始前就能确定的降级项，不发起网络请求。重复组支持确认后逐条删除，同时清理更新状态和边界。它不会把运行时桥接、全局页数不足列为语法降级。

普通搜索中的多词标签应加引号，例如 `artist:"example artist"`。本地追更和标签模式把完整值视作一个标签。命名空间、简写及表达式支持范围见[扫描与未读机制](scanning.md)。

热门、图片搜索、榜单等特殊模式不支持书签更新；明确指定非中文正向语言的书签显示语言冲突，不会自动替换成中文。

## 两类分割线

追更和书签的“上次更新到这”记录上次成功打开列表的边界。当前页使用进入前的旧边界，新打开位置通常在下次进入时生效；只检查更新不会直接移动它。

其他书签因相同 GID 联动清零时，符合条件的书签会把边界推进到它最近成功检查的顶部，保留检查后才出现的新漫画。边界不在当前加载范围内时，需要继续翻页才能看到。

首页“上次看到这里”是独立的手动标记。点击首页置顶按钮或长按分割线，确认后重置到当前已加载列表顶部。打开、刷新、翻页以及账号或站点切换不会自动移动它。

主页跳转到历史页时，如果已加载内容全部早于手动标记，不在每页顶部补画分割线。向上加载到保存边界的条目，或出现从新内容到旧内容的真实跨界时才显示；分页插入后同步重算分割线留白与长按区域。

## 自动追加中文

左侧开关控制普通浏览、订阅搜索、标签、上传者和过滤搜索的自动中文条件。已经存在正向 `l:`、`lang:` 或 `language:` 时保留原语言；保存的原始关键词不被改写。

更新检查采用自己的中文策略。非中文语言标签目前仍可加入本地追更，但逐标签结果与中文全局扫描的范围不一致，不能把二者计数视为等价。

## 追更导入导出

“设置 → 高级”可导出和导入 UTF-8 JSON，默认文件名为 `ehviewer-local-follows.json`。该文件只用于追更标签，不是漫画文件、全部书签或完整数据库备份。

```json
{
  "format": "ehviewer.local-follow-tags",
  "version": 1,
  "exportedAt": "2026-09-11T12:00:00+08:00",
  "count": 2,
  "tags": ["artist:example", "group:example"]
}
```

导入会预览非法和重复项，并让你选择合并或替换。替换会删除文件以外的原追更及其更新状态；新增项重新建立基线。

## 阅读队列与下载

成功显示应用内完整下载的页面后，漫画进入最近阅读队列，并记录最后成功显示的页码。下载中、失败、目录缺失、外部压缩包和普通在线内容不进入该队列。

下载页通过黄色“已观看 12/50”标签显示队列成员进度。队列页面右上角可设置自动删除和容量：范围为 1–100 部，默认 20 部；自动删除默认关闭，关闭时仍记录阅读，容量不会自动裁掉下载。

开启自动删除后，超出容量的旧条目会连同整部本地下载目录被永久删除。长按“移出队列”和“删除本地下载”是不同操作；删除失败时保留记录以供后续重试。

新归档下载支持应用内暂停、继续和完成导入。升级前没有保存 URL 的旧系统任务沿用兼容完成处理器，不具有新下载器的应用内暂停按钮。

## JM、登录和应用更新

“JM号查询”接受纯数字、`JM12345` 及支持的作品链接，显示资料并提供复制标题、浏览器打开。查询结果不是 EH 画廊，也不会保存为历史数据库记录；网页回退可能只提供部分资料。

“设置 → EH → 身份 Cookie”提供 IGNEOUS 手动刷新。刷新会先删除旧 IGNEOUS，再尝试获取新值，网络或代理问题仍可能导致失败。

“设置 → 更新与支持 → 检查更新”检查应用版本，与书签更新和 IGNEOUS 刷新是三个独立操作。
