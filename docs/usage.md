# 使用指南

[文档索引](README.md) · [常见问题](troubleshooting.md)

## 本地追更与服务器订阅

在列表或详情页长按标签，选择“追更”；再次长按可取消。右侧追更栏显示本机保存的标签，管理页支持搜索与删除。标签库可用时，名称显示中文翻译，下方保留原始查询。

本地追更不依赖服务器订阅，也不要求登录；实际能访问的画廊仍取决于站点、网络和账号权限。左侧“订阅”打开服务器 Watched，标签菜单中的服务器订阅、排除操作仍需要登录，两者是独立数据。

新条目先显示零基线，后台再细化从哪个时间开始计新增。第一次建立基线不会把全部已有漫画当作更新。

在主页长按漫画卡片，选择“下载”。漫画加入下载队列时，追更栏会从已记录这本漫画的每位作者名下各扣一条未读。例如两位合著作者原来分别有 3 条和 1 条更新，下载后会显示 2 条和 0 条。取消下载标签选择或重复操作不会多扣。原先显示 `20+` 的作者仍显示 `20+`，因为实际剩余数量无法从保留的明细确定。

## 追更更新漫画页

点击右侧追更栏顶部的“追更更新”，集中查看本地追更扫描发现的漫画。默认展示全部，可切换“未读”；同一本漫画只展示一次，卡片列出发现时命中的追更标签。按首次发现时间从新到旧排列，每次加载 50 本，最多保留最近 1000 本，超出后自动淘汰更早的更新记录，不删除漫画下载。

点击卡片进入漫画详情；从任意入口成功显示完整详情后，该漫画在此页标为已读。请求失败或取消不标记。进入本页、打开整个标签列表、下载或取消追更都不会直接清除这里的未读或历史记录；原追更栏角标仍按原规则工作，因此两者数量可能不同。返回时保留筛选和浏览位置。

本页只从此功能启用后的成功扫描中积累新增漫画，不回填旧更新，不包含书签或服务器订阅。首次建立追更基线也不收录历史作品；空页面时请在追更栏原刷新入口检查之后的新更新。进入页面不自动发起扫描，更新任务结束后刷新已保存记录。记录属于本机同步状态，不随现有数据库导出迁移。

## 检查追更和书签

点击书签或追更抽屉的刷新入口，选择“全局中文扫描”，均会用同一次中文全局扫描同时更新全部书签和追更；两栏显示同一任务进度，可从任一栏暂停、继续或停止。启动对话框显示两类数量与各自扫描边界。一栏为空仍更新另一栏，两栏皆为空时提示无可更新项目、不联网。逐标签、逐书签检查仍只更新对应类别；长按书签可以只检查这一项。

| 方式 | 行为 |
| --- | --- |
| 全局中文扫描 | 中文全局列表只扫描一遍，同时匹配追更和书签；未覆盖的追更逐标签补查，书签按原规则连续分页补查 |
| 逐标签检查 | 本地追更逐个读取标签第一页，未覆盖旧边界时显示数量下界 |
| 逐书签检查 | 连续翻页到旧边界或列表末尾，完成后保存新增 GID |
| 单书签检查 | 使用相同的书签分页规则，只处理所选书签 |

高级设置中的全局扫描上限为 1–300 页，默认 30 页；这是共享全局扫描的上限，不是逐书签扫描只读取 30 页。搜索请求间隔为 1.0–10.0 秒，默认 3.2 秒；小于 3.0 秒需要确认。修改间隔只影响新任务，暂停后继续沿用原任务设置。

联合全局任务暂停后继续（包括降级阶段）会重新从第一页扫描，沿用原任务请求间隔；旧版暂停的单类任务仍按原类型恢复。两栏任务历史同步展示联合任务结果，全部成功才更新两类成功时间。已成功提交的项目保留结果，停止任务不会回滚这些结果；尚未完成的书签分页不提交半截结果。

逐项检查暂停后，如果替换了追更作者、调整了书签顺序或改了书签查询，继续时会从第一项复查，以免跳过新项目。

## 重置书签扫描基线

长期没有检查书签、积压更新导致扫描太慢时，可以打开“设置 → 高级 → 重置所有书签扫描基线”。确认后，本机所有书签从重置时刻开始检查，跳过此前尚未检查的历史更新；已有未读数字、未读明细和“上次更新到这”分割线保留，书签名称、条件和排序不变。

重置只操作本地数据，不发起网络请求，也不会自动开始检查。重置所在秒及以前的内容视为历史，下一秒起仍可计为新增。重置后等待一段时间再检查，会统计这段时间内的新内容。该功能同样适用于账号切换和 E/EX 回退，但不会让不支持更新的查询变得可更新，也不改变本地追更。

运行中或已暂停的更新任务须先停止；可在抽屉刷新入口打开任务详情，已暂停任务也提供“停止”按钮，无须先继续联网。没有书签时不写入数据。重置不能恢复被跳过的历史更新，确认前请核对提示。

## 重置追更扫描基线

“设置 → 高级 → 重置所有追更扫描基线”位于书签重置按钮下方，两者分别操作。追更重置从当前时刻开始统计后续更新，清零所有现有追更未读数字和明细，并将阅读分割线更新到重置时刻；保留追更标签和真实检查时间。重置所在秒及以前的内容视为已读，下一秒起可以计新增。再次进入追更时，没有新增则分割线显示在第一本上方，作者追更也一样；有新增时，新内容显示在线上方。清零与跳过历史的操作无法撤销。

该操作只写本地数据，不联网、不自动检查更新，不重置书签或服务器 Watched。运行中或暂停的更新任务须先停止；空列表不会写入数据。全局扫描会从新的有效起点开始，逐标签仍使用原有第一页检查规则，追更最多保存 21 条未读明细。

## 未读数字和联动已读

- `0` 表示当前没有记录的未读更新；未初始化、失败和不支持查询应结合状态文字判断。
- `1–20` 显示数量；超过显示范围或计数只能确定下界时显示 `20+`。
- 书签保存全部未读 GID；本地追更最多保留 21 条明细。旧版本已裁掉的书签 GID 不会自动恢复。

成功打开一个书签会清除进入前捕获的未读批次；其他书签中的相同 GID 也会联动扣减。打开失败不会清除，打开过程中新增且不属于该批次的 GID 会保留。合法空结果也能清除原批次，避免站点已删除画廊留下永久计数。

这是“成功打开列表”的已读规则，不等于逐本阅读完漫画后才清零。

从追更栏进入标签会退出当前多标签组合，打开该标签的完整结果；进入书签也结束临时组合。卡片上点击标签和普通多标签搜索不清除原追更或书签的未读。

## 书签管理与检查报告

书签保存完整搜索条件。重命名保留更新状态，修改查询条件会重建基线。管理页支持名称和原始查询搜索；过滤期间禁用拖拽，清空搜索恢复排序。

书签设置页的“检查书签”只读取本地数据，报告重复查询和扫描开始前就能确定的降级项，不发起网络请求。重复组支持确认后逐条删除，同时清理更新状态和边界。它不会把运行时桥接、全局页数不足列为语法降级。

普通搜索中的多词标签应加引号，例如 `artist:"example artist"`。本地追更和标签模式把完整值视作一个标签。命名空间、简写及表达式支持范围见[扫描与未读机制](scanning.md)。

LOCATION 地点标签可用完整 `location:` 表达式添加追更或书签，例如 `location:school`；追更 JSON 导入导出支持这一分类。词库是否显示中文取决于本机词库是否包含对应译文。

热门、图片搜索、榜单等特殊模式不支持书签更新；明确指定非中文正向语言的书签显示语言冲突，不会自动替换成中文。

## 在线列表书签标签标记

首页、搜索、热门、订阅、追更、书签、图片搜索、排行榜的漫画列表及云收藏的列表和网格卡片会显示漫画已有标签中命中的书签标签。下载、历史、本地收藏和阅读队列不显示。各在线页面共用“显示标签翻译”设置，不新增独立开关；进入、返回页面、书签变更或自动中文设置变化时刷新标记。单标签书签优先使用保存的书签名称；名称是该标签的标准表达式，或是“中文分类:英文标签”的部分译名（例如“女性:focus handjob”）时，也跟随“显示标签翻译”开关用原始标签查词库。手动起的自定义名称和完整译名保持原样，缺少译文时保留原名称。组合书签只显示实际命中的标签，例如书签包含作者 A 和题材 B，漫画只有 A 时只标出 A；组合标签同样跟随翻译开关，没有译文时显示原始标签。显示翻译不会改写书签名称或搜索条件。

同一标签只显示一次，顺序跟随书签栏；如果也有匹配的单标签书签，优先显示该书签的名称，多个单标签书签取最前一项。每个标签单独使用浅色底色、细边框和圆角小框，12sp 加粗文字；标签自身保持单行，长名称在框内省略，整组自动换行、最多两排，过多时用 `+N` 表示剩余数量。深色与黑色主题使用柔和的对应底色和文字，无障碍描述保留完整名单。列表显示在封面右侧的上传者下方、评分上方；评分与下载/收藏图标、语言及页数位于同一排，评分靠左，其余信息靠右，底部显示分类和日期。网格标签显示在封面下方，卡片点击行为不变。

标记只提示订阅标签，不代表漫画满足书签的全部搜索条件：分类、评分、页数和排除标签不限制标记。正向语言条件仍须满足；自动中文跟随普通浏览开关，书签明确指定其他语言时保留该语言，自动追加的中文不额外显示为标记。

标记规则支持标签模式，以及普通搜索和过滤搜索中保存的标准标签组合；支持全部完整分类名（含旧 misc）及分类简写：a→artist、c/char→character、cos→cosplayer、f→female、g/circle→group、l/lang→language、loc→location、m→male、x→mixed、o→other、p/series→parody、r→reclass。大小写、引号和末尾 $ 沿用标准化规则；简写与完整分类名命中同一标签时只显示一次。分类简写扩展仅用于显示标记，书签检查及更新扫描仍按原规则处理；上传者、纯关键词、标签混全文、OR、通配符和无法可靠解析的书签查询不标记。使用网页标签与完整 API 标签；在线列表有可识别的书签时，为缺少完整标签的漫画批量补取 gdata，每批最多 25 本，不要求开启“显示页数”；云收藏翻页及移动、删除操作返回的列表也采用这一规则。API 标签不包含部分低权重弱标签，即使详情页能看到，批量补取后也可能不显示；已有完整数据不重复补取；网络或解析失败保留网页列表和已有标记。两种标签来源均缺失、API 补取失败或无法确认语言条件时可能不显示。此标记不改变未读、更新扫描或阅读分割线，更新扫描不启用新增补取。

## 列表分割线

从追更栏打开作者（`artist:`）时，“上次更新到这”画在当前已加载列表中最后一本命中本次未读 ID 的漫画下方。只有一条未读且它排在第一条时，线就在第一条下方。未读作品分散时只画一条线。进入时有未读但当前列表没有命中时隐藏，翻页加载到对应作品后再显示。本次打开期间按进入时的未读名单定位，追更栏清零后仍可看见这条线。进入时未读名单为空，则使用保存的阅读边界；没有新增时线位于第一本上方，不因数字为零而隐藏。空列表、首次尚无阅读边界或时间精度无法判断时不画线。

其他追更标签和书签的“上次更新到这”记录上次成功打开列表的边界。当前页使用进入前的旧边界，新打开位置通常在下次进入时生效。

其他书签因相同 GID 联动清零时，符合条件的书签会把边界推进到它最近成功检查的顶部，保留检查后才出现的新漫画。边界不在当前加载范围内时，需要继续翻页才能看到。

为区分同一分钟内的新旧作品，列表会按需补取顶部及分割线附近的秒级发布时间。补取失败时仍可浏览；无法确定的位置暂不画线，顶部时间不可靠时保留未读，下次成功刷新再完成清理。旧边界缺少可验证锚点时也不会猜测位置。作者按未读 ID 定位的分割线不受时间精度影响。

首页“上次看到这里”是独立的手动标记。点击首页置顶按钮或长按分割线，确认后重置到当前已加载列表顶部。打开、刷新、翻页以及账号或站点切换不会自动移动它。

主页跳转到历史页时，如果已加载内容全部早于手动标记，不在每页顶部补画分割线。向上加载到保存边界的条目，或出现从新内容到旧内容的真实跨界时才显示；分页插入后同步重算分割线留白与长按区域。

## 自动追加中文

左侧开关控制普通浏览、订阅搜索、标签、上传者和过滤搜索的自动中文条件。已经存在正向 `l:`、`lang:` 或 `language:` 时保留原语言；保存的原始关键词不被改写。

本地追更和书签列表使用固定中文查询，切换此开关仅刷新其书签标签提示，保留当前未读快照和分割线，不重新加载列表。

更新检查采用自己的中文策略。非中文语言标签目前仍可加入本地追更，但逐标签结果与中文全局扫描的范围不一致，不能把二者计数视为等价。

## 追更导入导出

“设置 → 高级”可导出和导入 UTF-8 JSON，默认文件名为 `ehviewer-local-follows.json`。该文件只用于追更标签，不是漫画文件、全部书签或完整数据库备份。

```json
{
  "format": "ehviewer.local-follow-tags",
  "version": 1,
  "exportedAt": "2026-09-11T12:00:00+08:00",
  "count": 2,
  "tags": ["artist:example", "group:example"]
}
```

导入会预览非法和重复项，并让你选择合并或替换。替换会删除文件以外的原追更及其更新状态；新增项重新建立基线。

## 阅读队列与下载

下载页右上角“排序 → 根据类型过滤 → 本地导入”可筛选已导入的外部归档和本地相册，普通网络下载不在此筛选结果中。筛选保留当前下载标签内的原有顺序，可通过“根据类型过滤”中的“全部”恢复当前标签列表；不会移动或删除下载文件。

“设置 → 下载 → 列表分页”开启后，当前下载列表超过 500 本时才显示分页；可选择每页 50、100、200、300 或 500 本。搜索、筛选和删除后按当前列表重新计算页数，原页码超出范围时回到最后一个有效页；列表减少到 500 本及以下时显示完整列表。

“设置 → 阅读 → 下载漫画连续阅读”开启后，从下载页打开漫画，读到末页再向后翻即可进入下一本。阅读顺序使用打开时的下载列表快照，保留当时的标签、搜索、筛选及排序结果，可跨越下载列表的分页；阅读途中新增的下载不会自动加入。已删除、目录缺失或没有可读图片的后续条目会跳过并提示，抵达最后一本可读漫画时提示结束。返回下载页后，刷新这次连续阅读经过的漫画进度。

成功显示应用内完整下载的页面后，漫画进入最近阅读队列，并记录最后成功显示的页码。下载中、失败、目录缺失、外部压缩包和普通在线内容不进入该队列。

下载页通过黄色“已观看 12/50”标签显示队列成员进度。队列页面右上角可设置自动删除和容量：范围为 1–100 部，默认 20 部；自动删除默认关闭，关闭时仍记录阅读，容量不会自动裁掉下载。

开启自动删除后，超出容量的旧条目会连同整部本地下载目录被永久删除。长按“移出队列”和“删除本地下载”是不同操作；删除失败时保留记录以供后续重试。

新归档下载支持应用内暂停、继续和完成导入。升级前没有保存 URL 的旧系统任务沿用兼容完成处理器，不具有新下载器的应用内暂停按钮。

归档内部文件按漫画和任务 ID 隔离，同名标题不会共用 ZIP。导入全部图片及保存下载记录成功后才显示完成；导入失败保留本地 ZIP 和恢复状态，可通过继续入口重试导入。旧任务若曾共用同名 ZIP，保留原文件并暂停，继续时从独立文件重新下载，不使用归属不明的断点。

导入数据库备份时保留本机已有下载目录映射，仅补充缺失映射。备份中的旧目录名不会替换本机当前目录；该操作不自动修复失效路径或移动漫画文件。

下载页菜单中的“导入本地相册”打开文件夹选择器，将所选目录及子目录内的支持图片按自然顺序复制到应用下载目录。导入后以文件夹图标区分，阅读不依赖原文件夹继续可用。重复选择同一来源会提示已导入；没有支持图片时不创建下载。相册和外部归档不进入自动删除阅读队列，普通完整下载继续显示“已观看”标记并支持连续阅读。

“重置阅读进度”会重置下载的阅读起始页，同时刷新 SpiderInfo 文件、缓存和运行中的阅读器位置。黄色“已观看”是最近成功显示页的队列记录，仍保留队列成员资格。

“设置 → 阅读 → 阅读刷新率”在 Android 11 及以上提供系统默认、最高、60/90/120 Hz。实际选择受屏幕支持模式和系统策略限制；默认沿用系统设置。长标题归档解压采用短临时目录及编号图片名，避免 ZIP 内长目录名超过文件系统限制，原画廊标题仍保留。

## JM、登录和应用更新

“JM号查询”接受纯数字、`JM12345` 及支持的作品链接，显示资料并提供复制标题、浏览器打开。查询结果不是 EH 画廊，也不会保存为历史数据库记录；网页回退可能只提供部分资料。

“设置 → EH → 身份 Cookie”提供 IGNEOUS 手动刷新。刷新会先删除旧 IGNEOUS，再尝试获取新值，网络或代理问题仍可能导致失败。

“设置 → 更新与支持 → 检查更新”检查应用版本，与书签更新和 IGNEOUS 刷新是三个独立操作。


## 恢复下载列表

在设置的下载分类中使用“恢复下载项”。逐目录优先读取文本 `.ehviewer`，其次读取 CBOR `.ehviewer`，最后尝试 `ComicInfo.xml` 的 Web 画廊地址。已有下载和同 GID 的重复目录跳过，原元数据不改写。画廊下架或网络补取失败时仍恢复本地记录，标题依次回退到目录名、GID；缺少有效 GID/token 的目录不会恢复。退出该设置页面会取消恢复，尚未提交的结果不会写入。该功能不代表对所有 CBOR 阅读进度或页面 token 的完整导入。
