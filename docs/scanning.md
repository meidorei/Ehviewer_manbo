# 扫描与未读机制

[文档索引](README.md) · [使用指南](usage.md) · [架构与数据](architecture.md)

本文按 2026-11-02 的追更与书签更新修复核对。旧文档中的“所有来源最多 21 条”“逐书签只检查第一页”已不适用。

## 边界、时间和计数

`FeedBoundary` 保存发布时间的 Unix 秒和该秒已见过的 GID 集合。发布时间更晚，或同秒但 GID 不在集合中，才视为新增。同秒结果必须完整处理，不能遇到一个已知 GID 就停止扫描。

| 状态 | 含义 |
| --- | --- |
| `*_SYNC` checkpoint | 对应查询已检查的内容边界 |
| `*_OPEN` checkpoint | 用户成功打开列表时记录的阅读边界 |
| `LOCAL_GLOBAL_CURSOR` | 同一账号、站点、任务类型与查询签名共享的扫描停止位置 |
| `CHECKED_AT` / `LAST_CHECKED_AT` | 实际完成检查的时间 |
| `UPDATED_AT` | 数据库记录写入时间 |

`globalTop` 是本轮中文全局列表顶部的发布时间及同秒 GID，不是运行任务时的系统时间。12:00 检查而最新内容发布于 11:58 时，内容边界应是 11:58。

`LOCAL_UNREAD_GALLERY` 以来源类型、来源键和 GID 去重。书签来源不限条数；追更保留 21 条。显示层的 `20+` 既可能表示超过显示上限，也可能表示扫描未完整覆盖的数量下界。

## 全局与逐项扫描

书签栏与追更栏的新全局请求统一为 `ALL / GLOBAL` 任务。每页中文全局结果只读取一次，同时按追更标签及书签精确查询匹配。两类游标仍按账号、站点和原任务类型独立保存；分别判断覆盖，直到双方均已越过完整边界时间组、列表末尾或同一轮页数上限。一侧首次建立来源基线不提前结束另一侧扫描，也不将历史匹配计作新增。同一画廊可同时计入各自来源，但共享分页统计只计一次。

共享扫描内存结果在扫描正常结束后才用于逐项提交；重复分页地址、无效时间戳、网络失败、暂停或停止会阻止未完成扫描提交。未覆盖的追更先按标签第一页补查，随后书签按既有精确/桥接/复杂查询规则处理。单项失败记录后继续其余项目，两类成功提交互不回滚；只有某类流程全部成功才能推进该类游标。不支持更新的书签记录失败，不发请求，也不记录整批成功。只有两类全部成功才更新两边成功时间，两栏历史显示同一联合任务结果。

全局扫描强制中文，从最新页向后读，越过共享游标的完整时间组后停止。页数范围 1–300，默认 30；来源首次建立时只设零基线，读取完整的顶部同秒 GID 组。如果全局页数上限截断了首次基线的同秒组，本轮报错，保留原边界。旧版本缺少共享游标时可从已有单项最旧边界开始迁移。

| 路径 | 完成后的边界 |
| --- | --- |
| 追更逐标签 | 读取第一页。无下一页时已覆盖全部结果，可精确计算本轮增量。有下一页且未越过旧边界时标记下界。空结果只更新检查时间 |
| 追更全局完整覆盖 | 分别计算匹配 GID。如果某标签的旧边界落后于共享游标，还须实际越过该标签的边界秒或读到末页，否则该标签单独补查。确认覆盖的标签推进至本轮 `globalTop` |
| 追更全局超过页数上限 | 降级逐标签第一页，沿用标签边界；降级队列全部成功后提交共享游标 |
| 普通逐书签、单书签 | 连续翻页到旧 checkpoint 或末尾，成功后推进至书签顶部；空结果不推进内容边界 |
| 书签全局精确匹配 | 完整覆盖后使用各自匹配结果，边界推进到本轮 `globalTop` |
| 书签旧边界桥接或页数降级 | 连续分页补算；取共享顶部与补查实际顶部中较新者，同秒合并 GID；全局游标仍只提交共享扫描顶部 |
| 书签复杂查询降级 | 连续分页检查，保留独立查询边界 |

任务内部的 `FIRST_PAGE` 是保留的方法名，不代表当前书签只扫描一页。实际入口 `checkBookmark()` 使用 `BookmarkScanAccumulator` 连续处理分页。

自动降级数量包含语法不支持本地匹配、旧 checkpoint 需要桥接、以及共享游标未被页数上限覆盖三类原因。它本身不是失败。

## 手动重置书签扫描起点

高级设置的批量重置为每个现有书签写入 `shared / BOOKMARK_RESET / 书签 ID / 查询签名` 时间下限，沿用 `BaselineBoundaryPolicy.provisional()` 的下一整秒边界。同一次重置使用同一时刻；重复操作不会把已有重置下限倒退。

扫描读取 `BOOKMARK_SYNC` 时使用已保存同步边界与重置下限中较新的边界，同秒合并已知 GID；所有单项、全局、桥接与复杂查询降级路径共用该读取方式，有效扫描边界始终不低于重置下限。写入同步 checkpoint 时只保存实际内容顶部，previous 取原始已保存顶部，不把重置时刻写入同步历史；普通自动基线允许从临时时间细化到较早的真实顶部，同秒已知 GID 继续合并。重置下限跨账号、站点共享，阅读用 `BOOKMARK_OPEN` 和联动已读所查询的实际同步顶部均不使用重置下限。

重置事务同时删除书签来源的旧基线队列与所有账号/站点的书签共享扫描游标。下次全局扫描从有效单项边界建立停止位置；共享游标成功写入时保留较新的原停止位置，避免结果顶部较旧时再次回扫。新的正常检查仍遵守完整成功才提交的规则。

批量重置与更新任务共用原子互斥入口；运行中或已暂停任务必须先停止。重置不联网、不新增检查成功记录、不清理未读，不触碰本地追更；删除书签或改变查询签名时清理相应重置记录，重命名保留。

## 手动重置追更扫描起点

独立的追更重置在同一事务中读取追更标签并写入 `shared / LOCAL_FOLLOW_RESET / 标准化标签 / 固定中文查询签名`。使用统一时刻的下一整秒作为下限，重复重置不倒退；空列表不写入状态。只清理 `LOCAL_FOLLOW` 的旧基线队列和 `FOLLOW` 共享游标，书签、服务器 Watched 和首页手动分割线保持不变。

`LOCAL_FOLLOW_SYNC` 扫描读取应用重置下限，覆盖逐标签、全局扫描、页数降级和 E/EX 回退；全局游标失效后从有效单项边界重建，成功提交不倒退原停止位置。同步 checkpoint 继续保存实际内容顶部及 previous，重置下限不混入同步历史或阅读边界；普通自动基线仍允许细化，同秒已知 GID 合并。

删除追更和替换导入移除标签共用清理方法，其 `LOCAL_FOLLOW%` 来源范围包含重置记录；保留标签不受影响，删除后重新加入按新条目初始化。保留原有追更 21 条明细、数量下界和第一页降级策略，不将其改为书签的连续分页规则。

## 标签与查询匹配

完整命名空间为：

```text
artist group parody character female male misc language
cosplayer mixed other reclass location
```

追更只接受标准 `namespace:value`，统一首尾空格、连续空白和大小写。完整多词值不会拆词；不要给追更标签加末尾 `$`，也不要使用命名空间简写。

书签的本地精确匹配支持标准标签、正负标签的 AND 组合、正向 uploader、分类、最低评分及页数范围。普通搜索的多词标签须带引号；标签模式按整体处理。标准标签末尾 `$` 可有可无。

更新扫描和书签诊断中，`l:` 和 `lang:` 可映射为 `language:`；其他简写如 `f:`、`m:` 未被识别时降级。全文关键词、标签混全文、OR、模糊表达式、通配符和负向 uploader 等无法由列表元数据精确重现的查询也降级。

同步上游 2.0.2.5 后，本地追更 JSON 和书签精确查询支持完整 `location:` 命名空间；翻译词库使用 `loc:` 前缀，但本地精确查询的简写规则不变，建议保存完整 `location:school`。

在线列表和云收藏的书签命中标签另由 `BookmarkTagMarkerPolicy` 显式启用分类简写解析，只用于卡片提示。它使用普通浏览的语言策略，按正向标签显示命中，不等同于更新资格或完整查询匹配；提示出现不代表该书签可参与更新。具体分类简写、显示和标签来源见[使用指南](usage.md)。

更新扫描除匹配能力判断外，还会先由 `BookmarkUpdatePolicy` 验证更新资格。特殊模式和非中文正向语言条件分别返回 `unsupported mode`、`language conflict`，不发更新请求。

书签签名包含 mode、分类、关键词、高级搜索、评分、页数及中文策略。名称不参与签名；条件变化会清理旧状态和边界并重建基线。

## 请求与提交完整性

更新使用 `EhEngine.getGalleryListForUpdate()`，不套用普通浏览的本地过滤器。更新解析读取列表中的 GID、token 和分页链接，然后每批最多请求 25 项 gdata，统一使用 API 的秒级发布时间。旧断点中已记录的 GID 从分钟细化至同一分钟内的实际秒数时仍视为已见。HTTP 失败、无法识别的结果页、无效画廊链接或 API 数据缺失会中止该项扫描。站点明确返回 `No hits found` 才能当作空结果。

在线书签提示使用的 `HomeBookmarkTagSupplement` 属于普通浏览请求的可选补取路径，仅为 `simpleTags == null` 的条目补取并复制 API 标签，普通失败保留原列表，取消和中断继续传播。提示合并网页 `tgList` 与 API `simpleTags`；更新精确匹配使用 `simpleTags`，不启用这一新增开关，仍使用上述元数据补齐机制，失败会中断对应扫描。卡片提示不写入未读、checkpoint 或全局游标。

搜索请求间隔在每次列表请求前执行，不额外限制 gdata、图片或普通浏览。任务创建时保存间隔快照。

书签扫描在跨页时合并顶部同秒的全部 GID，先在内存收集新增 GID，完整结束后由 `commitBookmarkScan()` 在事务中提交未读和 checkpoint。重复分页 URL、无效时间戳、暂停、停止和网络失败都不能提交该项半截结果。全局游标也只在对应流程成功后推进。

任务不是覆盖所有项目的单个数据库事务：前面完整成功的项目已经提交，后续项目失败不会回滚它们。应区分“单项提交完整性”和“整批任务全部成功”。

## 暂停、来源切换与恢复

`LocalUpdateService` 通过进程内活动标记限制单个任务，状态保存在 `LOCAL_REFRESH_JOB`；阶段包括准备、全局扫描、追更队列、书签队列和基线。

暂停或停止会取消当前网络请求并中断工作线程。逐项任务恢复前核对来源、队列顺序、标签或书签 ID 及书签查询条件。与启动时一致且此前无失败才沿用索引。数量相同但成员变更，或旧任务没有队列签名时，从头复查。联合全局任务继续时从第一页重新扫描，沿用原请求间隔。旧版暂停任务保留原单类范围，基线从未完成队列继续。进程重启将运行中的任务改为暂停，运行中的基线项改为待处理。

可用 IGNEOUS 优先 EX，否则使用 E；EX 请求失败会尝试 E。联合全局阶段切换 host 后清空两类本轮内存结果，重读两类游标并按新来源从第一页重新开始。书签分页途中切换 host 同样丢弃当前书签临时结果并从新站点第一页重扫，不使用旧站点全局顶部提交。同步边界按账号与 host 区分，具体数据范围见[架构与数据](architecture.md)。

## 追更更新漫画记录

`LOCAL_FOLLOW_UPDATES` 独立保存本地追更的更新漫画快照。沿用 `collectNewGids()` 的边界判断，在单项成功提交 checkpoint、未读的同一事务内写入新增漫画；在追更 21 条未读裁剪之前保存全部已检测新增。全局扫描、逐标签和降级共用该入口，书签、首次基线及未完成扫描不写入。此前完整成功提交的项目仍保留，不因后续项目失败回滚。

记录按 GID 合并，重复命中合并发现时的标签快照并更新漫画元数据，保留首次发现时间及已读状态；按首次发现时间、GID 倒序保留 1000 本。取消追更和旧未读清理不删除快照。新页独立已读只在完整漫画详情成功显示时设置，包括缓存和页面恢复；打开标签列表及下载本身不设置，原计数、打开边界和扫描游标保持既有语义。

新页每次扩展 50 本显示范围并重读有序前缀，避免更新插入或未读移出造成 offset 分页跳漏。页面进入、返回及任务结束重载本地数据，不发起扫描。旧未读只有 GID，缺少访问 token 和展示信息，因此不作历史回填。

## 打开列表与分割线

新增未读记录使用递增行号。分配行号和写入记录在同一事务内完成。即使下载扣数或其他页面清空了表，后来扫描到的记录也会超过旧页面保存的批次上限。空结果和检查失败只更新检查状态，保留事务提交时的未读数量。

主页新建下载记录时，在同一事务内按 GID 移除 `LOCAL_FOLLOW` 中对应的 `artist:` 未读明细，并按剩余明细重算各作者的计数。只处理入队时已有的未读记录，保留原计数状态（含下界）、检查时间及扫描和阅读边界。

进入作者追更时，用同一次查询取得该标签的未读 GID 和最大 rowid。页面保留这批 GID，用当前已加载列表中最后一个命中项定位分割线，支持页末、分页及页面重建。未命中时隐藏。显示 `20+` 的作者也只使用保留的未读明细。

其他追更及书签进入时读取旧打开边界，同时记录未读批次的 rowid 上限。成功打开后，作者、其他追更及书签都保存新的非空页面顶部，清除进入前批次。其他追更和书签在本次画面继续使用旧打开边界。书签合法空结果也清理该批次，但不写入空顶部。

打开列表的非空顶部必须具有可靠的秒级时间。普通 HTML 只提供分钟时间，浏览请求按需补取顶部分钟及旧边界分钟的 gdata；只复制发布时间和精度，不覆盖标题、标签等展示字段。补取失败仍显示列表，歧义位置不画时间分割线，顶部不可靠时不清本次未读、不写新打开边界。取消和中断继续传播。作者分割线始终按进入时未读 GID 定位，不改为时间比较。

边界及画廊显式保存 UNKNOWN/MINUTE/SECOND 精度。checkpoint 与全局游标在原 GID 字段使用 `@fb1:` 标头保存精度，继续兼容旧逗号 GID 格式；schema 不变。旧格式边界一律视为精度未知，仅在全部已保存锚点可验证时细化显示，不能把同分钟陌生 GID 一律当新增，也不能自动改写首页手动锚点。页面状态保存精度和进入批次；未读清理只在数据库提交成功后保存“已清理”，等待提交时恢复页面仍可重试。

完整追更入口退出多标签组合，书签入口同样结束临时组合；卡片标签、组合搜索及外部搜索参数属于临时搜索，不清原来源未读。固定中文的追更与书签页面切换全局自动中文时仅刷新标签提示，不重新捕获未读批次。请求等待旧边界加载完成，并绑定来源、页面 helper、首屏语义和进入时 rowid；切换来源、页面重建及历史分页响应不得误清未读。

书签清理还会删除其他书签中相同 GID 的未读关系。符合 `BookmarkUnreadClearPolicy` 条件的其他书签清零时，打开边界可推进至其最近成功更新边界；不能用稍后打开时的实时顶部代替，不能把部分减少或下界状态强行当成精确清零。

首页分割线使用独立手动机制，只有用户确认重置才改变。服务器 Watched 保留旧聚合边界实现，不应据此承诺新安装可自动建立该边界。

Watched 聚合扫描接口使用更新专用的列表解析与秒级时间。扫描会读完整个边界秒，计算时按 GID 区分同秒的旧作与新作。遇到循环分页、无效时间或时间顺序异常时返回失败。追更栏的刷新走本地追更流程。

主页跳转到历史页时，如果已加载内容全部早于手动标记，不在每页顶部补画分割线。向上加载到保存边界的条目，或出现从新内容到旧内容的真实跨界时才显示；分页插入后同步重算分割线留白与长按区域。
