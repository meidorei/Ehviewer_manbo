# 主模型提示与审核规则

使用 [v3 数据契约](schema.md)。模型输入只提供安全题名元数据和相关决策／公开来源，不发送数据库二进制、账号、设备／下载路径或凭证。每次只处理有界批次；输出严格 JSON，不附 Markdown 或解释前后缀。

## 全库 discovery

对当前 batch 每个 GID 独立标注一次。输入仅有 gid/originalPosition/title/titleJpn；输出 formatVersion=1、原样复制双指纹与 batchId、annotations。

提取活动前缀后真正的作者／社团名、可信跨语言作品别名、紧凑语义键及篇章线索。不要把汉化组、语言标签、活动名当成作者。仅保留有把握的别名；证据不够则空数组或 null，不凭空翻译出唯一身份。此阶段不宣称最终系列归属。

## 候选审核 candidate

候选、相似度、共享作者和连通分量是高召回线索，允许误召回。一起检查作者身份、主标题语义、作品支系和卷章证据：

- 同作者不同作品要拆开；不同作者的同名作品不能只凭同名合并。
- 作者跨文字别名须结合题名或公开页面核实。跨语言作品名、缩写续篇、合集及额外篇章可以补入已有系列，但必须说明依据。
- 重复翻译及重叠合集保留独立 GID；不要删除、去重或展开合集。
- 正篇、番外、合集、重制版记录为 category；真正的故事分支记录为 branch；不同翻译保留同类别、同分支、同位置。
- 明确区分第 0 章与未知；判断位置是否能与同组成员比较。位置不可靠时 position 可保留提取线索，但 orderReliable=false，不据此排序。
- 没有足够证据就独立 `item:GID`、needsHumanReview=true，填写候选和不确定理由。不要为了减少未决数量强行合并。

每个系列应使用稳定、无歧义的 canonicalSeriesId；不可仅用通用语义词作为跨作者身份。分批时携带先前接受的 ID／标题索引。

## 作者审核 author

审核完整作者桶的全部子批和已接受系列。关注带活动前缀标题、异体／罗马音作者名、跨语言题名、不同系列混入、缺成员、缩写续篇、番外和合集。作者一致不构成合并理由。桶的子批之间必须通过完整 GID 索引和相关系列卡片交叉检查。

## 未决审核 unresolved

使用本轮最新决策重新生成的未决索引，而非最初候选生成时的单例列表。复查被拒绝候选、新拆出的条目、跨批译名和待审关系，尝试寻找支持的关联；没有依据则明确保留独立。独立不等于遗漏，也不自动降低其展示优先级。

## 全局审核 global

按有界批次检查所有系列卡片、独立条目摘要和高频碰撞审核。低置信、跨语言、合集、番外和重制版附原始题名。检查重复系列身份、跨批拆散、同 ID 异名、错作者、错分支、顺序矛盾及遗漏。四轮均需完整覆盖，变化应进入本轮决策，不用文本备注掩盖数据冲突。

## 按需联网

只查询当前疑难作品的公开题名和作者。优先作者／社团、出版社或作品的公开页面，其次可交叉核实的公开目录。将 URL、访问时间、实际支持的关系及 sourceType="page" 写入 evidence。

不要将搜索摘要、主模型记忆或相似封面单独视为定论。无法访问、需要账户凭证或多个来源冲突时，保留独立／待审并说明限制，不绕过访问限制。脚本不新增模型 API，也不批量自动爬取或上传书库。

## 本轮交付

从当前 prepare 文件复制双指纹和 inputArtifactDigest。返回 schema 中的完整 v3 decisions，以及 reviewedGids、conflicts、summary。只有真实完成审核后才登记覆盖；不得生成空泛的“全部通过”记录代替判断。

每批只返回实际审核的 GID；跨候选重复 GID 的最终结论必须一致，否则先在主模型中解决。`audit merge` 会拒绝冲突；`audit record` 接受已汇总的完整一轮。完成四轮后才能 build 和生成可确认审核页。
